Identifikasi Masalah & Solusi

Klik panel di bawah ini untuk melihat latar belakang masalah dan solusi yang ditawarkan.


Pencatatan pesanan di warung secara manual sering memicu human error dalam menghitung subtotal pesanan yang banyak. Proses perhitungan kembalian uang juga memakan waktu sehingga antrean kasir menjadi panjang.


Membangun aplikasi kasir terminal dengan algoritma Pascal yang menerapkan:
1. Otomatisasi perhitungan subtotal & total.
2. Manajemen Array untuk menyimpan, mengedit, dan menghapus pesanan dinamis.
3. Validasi perulangan pembayaran untuk mencegah uang kurang.

Proses Pengolahan & Rumus

Kalkulasi Penambahan

subtotal = hargaMenu * jumlah

totalBelanja = totalBelanja + subtotal

Algoritma ini dieksekusi setiap kali user menekan opsi tambah menu.

Kalkulasi Pengurangan (Edit)

subtotalKurang = hargaItem * jumlahKurang

totalBelanja = totalBelanja - subtotalKurang

Jika `porsiAkhir == 0`, jalankan Array Shifting untuk menghapus elemen pesanan.

Kalkulasi Kasir

kembalian = uangBayar - totalBelanja

Divalidasi dengan logika kondisi IF uangBayar >= totalBelanja THEN ...

Langkah-Langkah Algoritma

Jalankan simulasi langkah algoritma dari awal hingga akhir transaksi.

  • 1. Mulai: Inisialisasi variabel totalBelanja = 0, jumlahPesanan = 0.
  • 2. Input: Masukkan Nama Pelanggan.
  • 3. Looping Pesanan: Tampilkan daftar 30 menu. Pengguna memilih menu dan jumlah.
  • 4. Pemrosesan: Hitung subtotal. Simpan ke dalam Array of Record.
  • 5. Looping Pembayaran: Meminta uang bayar. Validasi jika kurang.
  • 6. Cetak Struk: Cetak nama, seluruh isi array pesanan, total, dan kembalian. Selesai.

Analisis Source Code Pascal

type
    TPesanan = record
        namaMenu : string[40];
        harga    : longint;
        jumlah   : integer;
        subtotal : longint;
    end;
var
    pesanan : array[1..100] of TPesanan;
    jumlahPesanan : integer;
// Memilih menu menggunakan percabangan
case pilihanMenu of
    1: begin
        namaItem := 'Nasi Goreng Spesial';
        hargaItem := 20000;
       end;
    2: begin
        namaItem := 'Ayam Geprek';
        hargaItem := 15000;
       end;
else
    writeln('Menu tidak tersedia!');
end;
// Loop hingga uang mencukupi
repeat
    write('Masukkan uang bayar: Rp');
    readln(uangBayar);
    
    if uangBayar < totalBelanja then
        writeln('Uang kurang Rp', totalBelanja - uangBayar);
until uangBayar >= totalBelanja;

kembalian := uangBayar - totalBelanja;
